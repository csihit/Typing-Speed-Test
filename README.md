# Typing Speed Test

A modern and interactive Typing Speed Test built using HTML, CSS, and JavaScript. The project measures typing speed, accuracy, time, and errors in real time while providing instant visual feedback for every character typed.

The test automatically selects a random sentence and tracks your performance as you type.

## Features

- Real-time typing speed calculation (WPM)
- Live accuracy tracking
- Error counting
- Real-time timer
- Character-by-character correct/incorrect highlighting
- Random typing sentences
- 60-second maximum test duration
- Interactive test completion screen
- Restart and run-again functionality
- Responsive and lightweight design
- Modern dark purple UI with gradient effects

## Tech Stack Used

- **HTML** – Structure of the typing test interface
- **CSS** – Styling, responsive layout, gradients, animations, and visual effects
- **JavaScript** – Typing logic, WPM calculation, accuracy tracking, timer, error detection, and result handling

## How to Run

1. Download the repository (A ZIP file will be downloaded).
2. Extract the ZIP file on your computer.
3. Open the extracted folder.
4. Double-click **index.html** or open it in any web browser.
5. Click inside the typing area and start typing.
6. View your WPM, accuracy, time, and errors in real time.

**Note:** Make sure all files (`index.html`, `style.css`, and `script.js`) are kept in the same folder for the project to work correctly.
